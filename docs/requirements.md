# 要件定義

> ※一部は古い。2026-11-03以降の決定は `docs/decisions.md`(決定事項1〜)が優先。

## 目的と対象
タッチタイピングを身につけたい初心者が、iPhoneの横画面で片手ずつキー位置・指の担当を覚える。スマートフォン画面のタップは実際の物理キーボードの運指習得そのものではなく、位置記憶の補助教材と位置づける。

## MVP（最優先）
1. 左手・右手を切り替えられる。
2. QWERTYの各段の横ずれを再現した片手キー配列を表示する。ホームポジションのF/Jに目印を付ける。
3. 指の担当範囲を色分けし、凡例を表示する。
4. Lv.1 単キー、Lv.2 短い文字列（約3〜5字）、Lv.3 長い文字列（約5〜10字）を選択できる。
5. 出題文字列と入力済み部分・次のキーを区別して表示する。画面のキーをタップすると即座に正誤が分かる。
6. 誤入力はカウントするが入力位置を進めない。正しいキーを押したときだけ進める。全字正解でクリア表示、次問へ。
7. 練習時間・正答率・ミス数を表示。進捗・設定はブラウザ内に保存する。
8. iPhone Safariで利用でき、ユーザー登録やログインを要求しない。
9. タッチ対象は十分大きくし、横画面の表示領域に収まるようにする。

## 次の段階
- キー文字を隠す記憶テストモード。
- 30秒・60秒の時間制限モード。
- 苦手キー分析、日次練習履歴、前回の続きから再開。
- PWA（manifest / service worker / オフライン練習）。
- GAS + Google Sheetsによる管理者向け利用状況集計（利用者の事前同意を得る）。

## レベル別出題
- Lv.1: 片手のキーを1文字ずつ出題。まずホームポジション周辺を優先。
- Lv.2: 片手のキーだけで入力できる短い文字列。単語である必要はないが、練習意図を明示。
- Lv.3: 同じく片手のキーだけで入力できる長めの文字列。出題辞書は配列から自動生成・検証可能にする。
- 大文字・小文字の扱いは英字キーとして同一視し、Shiftキーは初期版では扱わない。
- JIS/USの記号キー差は要確認。初期版は英字キーを優先し、記号の追加は配列定義と実機確認後に行う。

## 受け入れ条件
- 左手の問題には左手側で表示したキーだけ、右手の問題には右手側で表示したキーだけが登場する。
- 問題の全キーを正しい順番で押した場合にのみクリアになる。
- 不正解で入力済み文字列は変わらず、ミス数が増える。
- 画面を更新しても設定・保存済みの練習結果を復元できる。
- iPhone横画面で意図しない横スクロールや誤タップが起きにくい。
- 友人はURLを開くだけで練習開始できる。

## 未確定事項
- JISキーボードの厳密な配列範囲、記号キーの扱い。
- 問題文の自然さとランダム出題の比率。
- 効果音の有無（初期状態はミュート推奨）。iPhone SafariでWeb振動APIに依存しない。
- 共有データの保存期間と利用者識別方法。
